# Настройка администратора

1. Зарегистрируйте пользователя через форму сайта.
2. В базе данных выполните запрос, указав email созданной учётной записи:

```sql
UPDATE users SET role='admin' WHERE email='ВАШ_EMAIL';
```

Для публичного размещения используйте уникальный сложный пароль и защищённое HTTPS-соединение.
